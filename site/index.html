What it does

Exact brackets

Single and double elimination, GSL and eight-team groups, Swiss stages: outcomes are enumerated, not sampled, wherever the format allows.

Player values

Rating, win, role and booster points per round, with padding and elimination rules applied the way the fantasy game scores them.

Top 5 rosters

Best average, best single outcome and most likely winner, each with roles and boosters assigned across the roster without clashes.

Point sources

Click any player to see where the points come from: opponents, chances, boosters, and the exact bracket behind a ceiling.

Getting started

  1. Download and run the installer.
  2. Open the app. It connects to the valuation server automatically; the Tournament tab shows the active event.
  3. Use the Database tab for player and team detail, and the Top 5 tabs to build a roster.

Valuations are published by the server for the current event and refreshed nightly. The app is read-only: it cannot import data or start runs.
